# Workflow: Brand Audit
## Department: Brand Strategy

Run this workflow when brand output from any department feels off-brand, inconsistent, or when preparing for a new season/drop.

---

## Step 1 — Trigger Conditions

Initiate a brand audit when any of the following occur:
- Copy is submitted that uses banned words from `role-definition.json`
- A product page, email, or ad feels "generic" or "mass market"
- A collaborator reports that output "doesn't sound like NCD"
- A new product category is being introduced
- Quarterly review checkpoint

---

## Step 2 — Audit Scope

Define which channels/assets are under review:
- [ ] Product page copy
- [ ] TikTok captions and hooks
- [ ] Email flows (subject lines, body copy)
- [ ] Paid ad copy
- [ ] Homepage and collection page copy
- [ ] Social media bio and link-in-bio pages

---

## Step 3 — Brand Voice Checklist

For each piece of content under review, answer:

| Check | Pass | Fail |
|---|---|---|
| Would a high-standard man feel seen by this copy? | | |
| Does it avoid banned words? | | |
| Does it speak to one person (not everyone)? | | |
| Does it communicate earned quality — not hype? | | |
| Does it imply scarcity naturally — not desperately? | | |
| Is it direct, short, and unafraid? | | |
| Does it make the brand feel exclusive without being elitist? | | |
| Is it better than what a competitor would write? | | |

---

## Step 4 — Failure Analysis

For each FAIL:
1. Identify the specific phrase or concept that fails
2. Write the corrected version using brand voice guidelines
3. Log in `docs/brand-bible.md` under "Audit Corrections"
4. Issue a voice calibration memo to the responsible department (`workflows/voice-calibration.md`)

---

## Step 5 — Output Report

Deliver audit report in this format:

```
BRAND AUDIT REPORT
Date: [DATE]
Scope: [CHANNELS REVIEWED]

OVERALL SCORE: [X/8 checks passed]

PASSING ITEMS:
- [list what's working]

FAILING ITEMS:
- [Asset]: [What failed] → [Corrected version]

DEPARTMENT NOTIFICATIONS SENT:
- [dept] re: [specific issue]

BRAND BIBLE UPDATES:
- [any new rules or examples added]
```

---

## Step 6 — Handoff

- Send corrected copy to `02-copywriting` for rewrite
- Send visual direction notes to `05-creative-direction`
- Archive audit report in this folder as `audit-[YYYY-MM].md`
