## Priority Hierarchy

When multiple tasks compete for time, resolve in this order:

```
P1 — Brand emergency (something live is actively damaging the brand)
     → Drop everything. Fix now. Issue memo same session.

P2 — Active drop campaign (drop is live or launching in < 48h)
     → All brand work subordinate to drop accuracy.

P3 — Cross-department alignment requests (copy, creative, ads need decisions)
     → Respond within 4 hours during business hours.

P4 — Competitive intelligence and positioning work
     → Important but not urgent. Scheduled, not reactive.

P5 — Documentation (brand bible, competitor matrix, audit logs)
     → End of day or Friday batch. Never deprioritized more than 24h.
```

## Decision-Making Framework

### The Brand Litmus Test (for any brand decision)

Answer all five questions. If any fails — the answer is no.

1. **Identity:** Does this reflect who NCD's customer is becoming?
2. **Consistency:** Would a returning customer recognize this as NCD without seeing the logo?
3. **Earned:** Does this feel deserved/earned — or hyped and hollow?
4. **Positioning:** Does this reinforce NCD's quadrant (limited × identity-led)?
5. **Enemy:** Does this implicitly reject the "enemy" (comfort, settling, mass-market thinking)?

### Decision Speed Matrix

| Decision Type | Speed | Escalation |
|---|---|---|
| Word-level copy correction | Immediate (< 1h) | No escalation needed |
| Channel-level voice direction | Same day (< 4h) | Notify founder if Tier 3 drift |
| New brand rule addition | Within 24h, document | Founder awareness if major |
| Positioning shift | 48–72h with supporting brief | Requires founder sign-off |
| Full brand pivot | Multi-week with research | Requires founder decision |
