# Brand Strategy — Daily & Weekly Schedule
## Department: 01 | Employee: Brand Strategist

---

## Main Objective

Maintain the NoComfortDept brand as the defining voice in dark luxury masculine streetwear. Every output from every department must pass through the brand's framework. The Brand Strategist's job is to make that framework so clear, so internalized, so operationally embedded that it enforces itself.

**North star metric:** Every piece of NCD content should be unmistakably NCD without a logo.

---

## Daily Responsibilities

### Every Day (15–30 min)

| Time | Task | Output |
|---|---|---|
| Morning | Brand pulse scan — review all live content (TikTok, email, ads) against brand bible | Pass/flag list |
| Morning | Review any copy submitted by `02-copywriting` overnight | Approval or calibration memo |
| Ongoing | Respond to brand drift alerts from any department | Voice calibration memo |
| EOD | Log any new brand decisions made today in `docs/brand-bible.md` | Brand bible update |

### Drop-Week Daily Additions
- Review all drop-specific copy against campaign narrative
- Confirm creative assets align with moodboard before posting
- Monitor social comments for brand perception signals

---

## Weekly Responsibilities

### Monday — Brand Week Open
- [ ] Review all content published in the past week across channels
- [ ] Score each piece against brand voice checklist (8-point audit)
- [ ] Issue voice calibration memos for any Tier 2+ drift
- [ ] Set the week's brand priority (drop campaign / evergreen / audit)

### Tuesday — Competitive Intelligence
- [ ] Scan competitor activity: Fear of God, Represent, ASRV, emerging brands
- [ ] Update `docs/competitor-matrix.md` with any new positioning moves
- [ ] Identify if any competitor has encroached on NCD's whitespace
- [ ] Brief `06-paid-ads` if a competitor's ad creative is outperforming NCD

### Wednesday — Strategy & Positioning
- [ ] Work on active positioning project (new category, seasonal narrative, campaign theme)
- [ ] Run `workflows/positioning.md` for any open positioning questions
- [ ] Deliver positioning brief to relevant departments if applicable

### Thursday — Cross-Department Alignment
- [ ] Sync with `02-copywriting` — review week's copy output, set next week's angle
- [ ] Sync with `05-creative-direction` — confirm visual direction aligns with narrative
- [ ] Review `04-tiktok-growth` content calendar for brand alignment

### Friday — Documentation & Planning
- [ ] Update brand bible with week's decisions and corrections
- [ ] Finalize competitor matrix updates
- [ ] Write campaign narrative brief for next week if a drop is approaching
- [ ] Log weekly brand health score in `operations/kpis-and-deliverables.md`

## Example Daily Workflow (Standard Day)

```
08:00  Open TikTok, Instagram, email — scan all live content
       → Flag: One email subject line uses the word "comfortable"
       → Action: Issue Tier 1 calibration memo to copywriting

08:20  Review two product descriptions submitted by copywriting overnight
       → Pass: Blackout Hoodie description
       → Flag: Combat Tee description leads with adjective not spec
       → Action: Return with specific edit (sentence 1 rewrite)

08:45  Check routing queue — any tasks escalated to brand strategy?
       → One: TikTok Growth asking if a trending audio fits the brand
       → Action: Assess against brand bible section 4 (visual/audio standards)
       → Decision: No — audio is too mainstream pop. Memo sent.

09:00  Core work — draft Q2 campaign narrative for summer drop
       → Research: What is the campaign enemy? (Softness? Comfort? The ordinary?)
       → Draft: 1-page campaign narrative brief

11:00  Update brand bible with today's audio decision as a new rule

11:15  EOD check — any pending approvals? Any new routing items?

11:30  Done
```

## Example Weekly Workflow (Drop Week)

```
MON  Brand audit of all pre-drop content. Score: 7/8. Flag 1 caption.
     Issue calibration memo. Set week priority: Drop campaign.

TUE  Competitor scan. Represent just ran a similar colorway drop.
     Brief: "NCD is limited-run dark. Represent is wide-release muted.
     Our angle: archive language. Theirs: restock-friendly."
     Send brief to copywriting and tiktok-growth.

WED  Finalize drop campaign narrative: "Drop 5 — The Standard."
     Enemy: men who buy for the label, not the craft.
     For: the man building something. Not performing it.
     Deliver to copywriting, creative-direction, tiktok-growth.

THU  Sync with copywriting — confirm product copy uses campaign language.
     Sync with creative-direction — confirm moodboard reflects "discipline over display."

FRI  Update brand bible with Drop 5 narrative.
     Log week's brand health: 8.5/10 (one minor drift, corrected same day).
     Set Monday priority: post-drop audit.
```
