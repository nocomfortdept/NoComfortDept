# NoComfortDept — Moodboard Guide
## Maintained by: Creative Direction

---

## How to Build an NCD Moodboard

Every drop and campaign gets a moodboard before a single photo is taken. The moodboard is the creative brief made visual. If the photographer can't shoot from the moodboard, the moodboard needs work.

---

## Moodboard Structure (6 images minimum)

| Slot | Purpose |
|---|---|
| 1 | **The Atmosphere** — the overall world this drop lives in |
| 2 | **The Light** — the exact light source and quality |
| 3 | **The Man** — the character, not a celebrity reference |
| 4 | **The Space** — the environment, one clear example |
| 5 | **The Detail** — a macro reference for product close-ups |
| 6 | **The Tone** — the color grade reference (still from a film or existing image) |

---

## Reference Vocabulary

When sourcing moodboard references, use these search terms:

**For atmosphere:**
`dark masculine editorial` / `industrial fashion photography` / `concrete architecture portrait` / `cinematic menswear dark`

**For light:**
`directional gold light portrait` / `Rembrandt lighting menswear` / `single source dramatic portrait`

**For tone/grade:**
`crushed blacks film still` / `desaturated masculine color grade` / `dark cinematic color palette`

**Never reference:**
- Bright lifestyle brands (Gymshark, Nike campaign)
- Warm golden-hour photography
- Fashion-forward avant-garde (too far from wearable)
- Anything that reads "gym motivation poster"

---

## Moodboard File Format

Save moodboards as:
- PDF or Figma frame
- Named: `NCD-Moodboard-[Drop#]-[YYYY-MM].pdf`
- Stored alongside the creative brief

## Seasonal Direction Notes

### Winter Drops
- Deeper shadows, cooler tones (steel-cold light source)
- Heavier fabric details — texture emphasis
- Interior spaces: raw concrete, exposed steel

### Summer Drops
- Same darkness — do not go bright for summer
- Warmer single light source (gold accent)
- Exterior: pre-dawn, post-dusk only — never full sun

### Drop Campaign (not seasonal)
- Tied to campaign narrative from `01-brand-strategy`
- Moodboard reflects the "enemy" of the campaign (comfort, mediocrity, etc.)
- Model energy matches the campaign's call to action
