# Workflow: Creative Brief (Master Template)
## Department: Creative Direction

Use this master brief for all shoots and campaigns. Tailor to photo or video using `photo-brief.md` or `video-brief.md` for additional detail.

---

## Creative Brief Template

```
CREATIVE BRIEF
Brief ID: CD-[###]
Drop / Campaign: [Name]
Date issued: [DATE]
Requested by: [Department]
Approved by: Creative Director

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THE ONE LINE
[What is this entire creative about in one sentence?]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THE MAN
Who is in this content? Be specific:
- Age range: ___
- Mindset: ___
- What is he doing / being in this content? ___
- What does he NOT do / NOT look like? ___

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THE PRODUCT
What is being shot:
- Product name: ___
- Colorway(s): ___
- Key feature to show: ___
- Key feature NOT to obscure: ___

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THE FEELING
What should the viewer feel in the first 3 seconds?
[ ] Power / authority
[ ] Quiet confidence
[ ] Earned luxury
[ ] Discipline / grit
[ ] Exclusivity
[ ] Dark aesthetic immersion

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ENVIRONMENT
Location:
[ ] Industrial / raw space
[ ] Empty concrete environment
[ ] Dark studio
[ ] Urban minimal
[ ] Natural: only if dark and minimal (no greenery, no bright sky)

Background color temperature: [ ] Cool / [ ] Warm / [ ] Neutral (black)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LIGHTING
Primary source: ___
Color temperature: [ ] Warm (gold) / [ ] Cool (steel) / [ ] Mixed
Shadows: [ ] Deep and crushed / [ ] Soft / [ ] Flat (never)
Key light direction: [ ] Side / [ ] Rembrandt / [ ] Above / [ ] Below

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VISUAL REFERENCES
[3 reference images or moodboard link — never use competitor brands as reference]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DELIVERABLES
Format: [ ] Photo / [ ] Video / [ ] Both
Ratio(s): [ ] 9:16 / [ ] 3:4 / [ ] 1:1 / [ ] 16:9
Quantity: ___
Due date: [DATE]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

APPROVAL REQUIRED FROM: Creative Director
FINAL DESTINATION: [TikTok / Paid Ads / Product Page / Email / All]
```

## Asset Review Format

When reviewing submitted assets:

```
ASSET REVIEW
Brief ID: CD-[###]
Asset: [File name or description]

APPROVED: [ ] Yes / [ ] No / [ ] Revision

IF REVISION:
1. [Specific issue → specific fix]
2. [Specific issue → specific fix]

CANNOT USE BECAUSE: [If rejected outright]
```
