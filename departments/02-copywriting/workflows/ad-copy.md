# Workflow: Ad Copy
## Department: Copywriting → Paid Ads

Use this workflow when `06-paid-ads` sends an ad creative brief requiring copy.

---

## Inputs Required (from Paid Ads)

- [ ] Campaign objective (awareness / conversion / retargeting)
- [ ] Audience tier (cold / warm / hot)
- [ ] Product being featured
- [ ] Visual format (static image / carousel / video / UGC)
- [ ] Platform (Meta / TikTok Ads / Google)
- [ ] Key message or angle

---

## Copy Deliverables Per Format

### Meta / Instagram Static Ad

| Field | Max Length | Notes |
|---|---|---|
| Primary Text | 125 chars | Punchy — first line must hook |
| Headline | 40 chars | Noun-forward, identity-led |
| Description | 30 chars | Spec or urgency |
| CTA | Platform options | "Shop Now" default |

**Primary Text Formula by Audience:**

*Cold (Discovery):*
```
[Identity statement that earns attention].
[Specificity that proves it].
[One honest scarcity signal].
[Link or CTA]
```

*Warm (Retargeting):*
```
[Callback to what they saw].
[Address the hesitation].
[Remove the risk — returns, quality].
[Final push].
```

*Hot (Last-touch):*
```
[Urgency — units, time].
[Single product name + price].
[CTA].
```

---

### Meta Carousel Ad

- **Card 1:** Hook card — identity statement, product silhouette
- **Card 2:** Material spec — weight, construction, fabric
- **Card 3:** Fit detail — how it sits on the body, shoulder structure
- **Card 4:** Lifestyle — the man in his world
- **Card 5:** CTA card — price, stock count, "Shop Now"

Copy for each card: 1–2 lines max.

---

### Video Ad Script Framework (15–30 sec)

```
0:00–0:02  [HOOK] — Identity statement or pattern interrupt
0:02–0:08  [BUILD] — Product in motion, spec overlay
0:08–0:20  [PROOF] — Construction detail, quality signal
0:20–0:25  [CLOSE] — Scarcity + CTA
0:25–0:30  [BRAND] — Logo + tagline hold
```

---

### Google Search Ad

| Field | Limit | Formula |
|---|---|---|
| Headline 1 | 30 chars | Product + Key Spec |
| Headline 2 | 30 chars | Brand Name + Drop number |
| Headline 3 | 30 chars | Urgency or USP |
| Description 1 | 90 chars | Identity statement + quality signal |
| Description 2 | 90 chars | Shipping/returns trust + CTA |

## Copy Bank — Approved Swipe Phrases

**Primary Text Openers:**
- "This isn't hype. It's 400gsm."
- "NCD doesn't restock. When it's gone —"
- "Built for the man who already decided."
- "Drop [#] is live. [#] units."
- "Your standards. Applied to what you wear."

**Urgency Closers:**
- "[#] units left. No restock."
- "This drop closes at midnight."
- "Archived after sellout. Final units."
- "Ships in 24 hours."
