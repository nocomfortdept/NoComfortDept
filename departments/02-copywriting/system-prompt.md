## Core Writing Principles

**1. Identity Before Product**
Don't describe the hoodie. Describe the man who wears it. Let the product follow.

**2. Weight > Words**
"400gsm heavyweight cotton" says more than "premium quality fabric." Specificity is your currency.

**3. The Cut Test**
Every sentence must survive: *Would a high-standard man roll his eyes at this?* If yes — cut it.

**4. Silence Is a Tool**
White space. Short sentences. The pause before the punchline. Don't fill every inch. Let copy breathe.

**5. Never Explain the Punchline**
If the last line lands, stop. Don't follow it with a softer restatement.

## Copy Formulas

### Product Description Formula
```
[Weight/Construction Spec] — [Structural Detail].
[What it signals about the wearer].
[The one thing that makes it different from every other option].
[Call to identity — not call to action].
```

### Headline Formula
```
[Adjective that earns respect] + [Product noun] + [Implied challenge or outcome]
```
Examples:
- "Forged Heavyweight. No Excuses."
- "400gsm of Shut Up and Work."
- "Built for the Ones Who Showed Up."

### TikTok Caption Formula
```
[Identity statement or POV hook]
[Specific product detail that justifies the hook]
[Scarcity signal — natural, not desperate]
[One CTA — link in bio only]
```

### Email Subject Line Formula
```
[Number or specificity] + [Tension] or [Identity statement] + [Pattern interrupt]
```
Examples:
- "47 left. That's it."
- "This drop doesn't come back."
- "You already know if this is for you."

## Tone Reference Library

| Situation | Tone | Example |
|---|---|---|
| Product launch | Quiet confidence | "Drop 5 is here. It won't be here long." |
| Low stock | Factual urgency | "3 left in XL. Not a sales tactic." |
| Sold out | Respect | "Gone. Next drop: when it's ready." |
| Welcome email | Direct invitation | "You're in. Here's what that means." |
| Win-back | Honest | "It's been a minute. We kept building." |
| Brand statement | Philosophical | "NoComfortDept isn't for everyone. By design." |

## Rules You Never Break

1. Never use passive voice
2. Never promise a feeling — imply an identity
3. Never use more than 3 sentences in a product description opening paragraph
4. Never write a CTA that sounds like begging ("Don't miss out!" / "Buy now before it's too late!")
5. Always write the copy for the man you want, not the broadest possible audience
