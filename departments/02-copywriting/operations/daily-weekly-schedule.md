# Copywriting — Daily & Weekly Schedule
## Department: 02 | Employee: Head Copywriter

---

## Main Objective

Produce every word that represents NoComfortDept — across every channel, every format, every touchpoint. Own brand voice at the execution level. Write copy so precisely NCD that no calibration memo is needed.

**North star metric:** Add-to-cart rate on product pages. Every word on the page either drives the click or costs it.

---

## Daily Responsibilities

### Every Day (60–90 min)

| Time | Task | Output |
|---|---|---|
| Morning | Review Brand Strategy's daily pulse flags | Address any calibration memos first |
| Morning | Check copy requests in queue (product, ad, email, caption) | Prioritized task list |
| Core work | Write copy for highest-priority item in queue | Draft delivered to requestor |
| Ongoing | Add completed copy to `docs/copy-vault.md` | Vault stays current |
| EOD | Review tomorrow's drop/launch needs — anything that needs writing tonight? | Pre-planned queue |

### Drop-Week Daily Additions
- All drop copy goes first — urgency bar text, email subject lines, countdown copy
- Review every piece of public-facing copy before it goes live
- Write same-day urgency copy for stock updates ("X units left")

---

## Weekly Responsibilities

### Monday — Queue Review & Planning
- [ ] Pull all copy requests for the week from all departments
- [ ] Prioritize: P1 (live/launch copy) → P2 (drop prep) → P3 (evergreen)
- [ ] Load current campaign narrative from Brand Strategy
- [ ] Review copy-vault for any pre-written copy that can be repurposed

### Tuesday — Product Copy Day
- [ ] Write or update all product descriptions in queue
- [ ] Run through product-copy workflow for each (`workflows/product-copy.md`)
- [ ] Deliver to Shopify CRO for implementation
- [ ] Add to copy-vault

### Wednesday — Ads & TikTok Copy
- [ ] Write ad copy for any active or upcoming paid campaigns
- [ ] Write TikTok captions for week's content calendar
- [ ] Deliver ad copy to `06-paid-ads`
- [ ] Deliver TikTok captions to `04-tiktok-growth`

### Thursday — Email Copy
- [ ] Write email body copy for any flow emails in queue from `07-retention-email`
- [ ] Review and refine any email sequences in testing
- [ ] Update headline-bank with any new subject lines that performed well

### Friday — Audit & Archive
- [ ] Self-audit week's output against brand voice checklist
- [ ] Update copy-vault with week's approved, delivered copy
- [ ] Flag to Brand Strategy any copy that felt uncertain about brand alignment
- [ ] Note any copy angles that resonated for future reference

## Example Daily Workflow (Standard Day)

```
08:00  Check calibration memos from Brand Strategy
       → One memo: Combat Tee description, sentence 1 leads with "super soft"
       → Fix immediately: replace with "240gsm structured jersey"
       → Resubmit to Brand Strategy for re-approval

08:20  Check copy request queue
       → 2 requests: Stealth Crewneck description + 3 TikTok captions for tomorrow's post
       → Priority: crewneck first (product page goes live today)

08:30  Write Stealth Crewneck description
       → Open product-copy workflow
       → Confirm: 340gsm, shoulder-forward, garment-washed
       → Draft tagline: "Heavy enough to hold shape. Light enough to move in."
       → Draft description (5 sentences, spec-led, identity close)
       → Features list: 5 pipe-delimited specs
       → Run brand checklist: all pass
       → Deliver to CRO for implementation

09:45  Write 3 TikTok captions
       → Open hook-vault for reference angles
       → Caption 1: Product Truth pillar — fabric macro video
       → Caption 2: Drop Mechanics — "2 days left, 34 units"
       → Caption 3: Identity Mirror — dark morning content
       → Deliver to TikTok Growth

10:30  Update copy-vault with today's outputs

10:45  Check tomorrow's needs: any drop copy due? Any email sequences pending?

11:00  Done
```

## Example Weekly Workflow (Pre-Drop Week)

```
MON  Load Drop 5 campaign narrative from Brand Strategy.
     Enemy: "men who perform instead of build."
     Priority all week: drop copy first.

TUE  Write all product copy for Drop 5: Blackout Hoodie V2 + Stealth Set.
     Taglines, descriptions, features. Deliver to CRO by 5pm.
     Add to copy-vault.

WED  Write Drop 5 ad copy:
     - Cold angle: identity-led ("for men who already decided")
     - Warm retargeting: objection-handling ("you were right to look twice")
     - Hot: urgency ("47 units. Ships tomorrow.")
     Deliver to Paid Ads.
     Write 5 TikTok captions for drop week. Deliver to TikTok Growth.

THU  Write drop announcement email + abandoned cart email variants for Drop 5.
     Subject lines: "Drop 5 is live." / "Still there." / "This is the last email."
     Deliver body copy to Retention.

FRI  Self-audit all drop copy. Score: 9/10 (one tagline revised).
     Update copy-vault. Log week's output.
     Brief: 11 pieces of copy delivered, all approved first-pass.
```
