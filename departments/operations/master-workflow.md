# NCD Master Company Workflow
## How the 7 Departments Operate as One System

---

## Overview

NoComfortDept runs as a 7-department machine. Each department has a distinct job. Together they form one loop: **Brand defines → Content creates → Paid amplifies → Shopify converts → Email retains → Creative makes it look like NCD.**

Every action taken by any department feeds back into this loop.

## The Two Operating Modes

NCD operates in two modes. All 7 departments shift behavior based on which mode is active.

### Mode 1: Standard Operations (Between Drops)

Departments run their weekly rhythms independently. Output is steady, systematic, low-urgency.

```
BRAND STRATEGY   → Weekly calibration. Competitive scan. No active brief.
COPYWRITING      → Evergreen copy improvements. A/B test copy variants.
SHOPIFY CRO      → A/B tests running. LP optimization. Metric tracking.
TIKTOK GROWTH    → 3–5 posts/week. Content pillar rotation. Audience building.
CREATIVE DIR     → Shoot briefs for upcoming drops. Asset library maintenance.
PAID ADS         → Cold prospecting at low budget. Retargeting warm audience.
RETENTION        → Flows running. Win-back campaigns. List hygiene.
```

### Mode 2: Drop Mode (D-14 to Sold Out)

All departments synchronize around the drop. Urgency increases. Communication tightens. Every output serves one goal: sell the drop.

```
D-14  Brand Strategy issues Drop Narrative Brief → All departments
D-10  Creative Direction confirms shoot complete → Assets to all
D-7   Copywriting delivers all drop copy → Email, Ads, TikTok, PDP
D-7   Retention builds drop email sequence (VIP, announcement, alert, sold-out)
D-7   Paid Ads briefs creative, sets up campaign structure
D-5   TikTok Growth begins pre-drop build content ("something coming")
D-3   Paid Ads campaign built in Ads Manager (not yet live)
D-3   Shopify CRO drop LP live on staging, final QA
D-1   Paid Ads final QA + scheduled for drop time
D-1   Retention VIP email scheduled (sends 24h before public drop)
D-1   TikTok Growth posts "drop tomorrow" reveal content
D-0   Everything fires simultaneously:
        - Retention VIP email already out, drop email goes at 8am
        - Paid Ads campaign goes live at drop time
        - TikTok Growth posts drop announcement + links in bio updated
        - Shopify CRO confirms LP is live, ATC working, checkout clean
        - Creative Direction on standby for any visual issues

SOLD OUT:
        - Paid Ads: pause cold/warm, run "waitlist" ad if applicable
        - Retention: send sold-out email ("Gone. Next drop: when it's ready.")
        - TikTok Growth: post sold-out reaction content ("we weren't ready for this")
        - Copywriting: update PDP copy to sold-out state
        - Shopify CRO: activate waitlist capture on PDP
```

## The Weekly Company Rhythm

Even in standard mode, the company follows a shared weekly cadence.

```
MONDAY — Review
  All departments: pull last week's numbers.
  Brand Strategy: sends weekly brand pulse to all departments.
  Paid Ads: week-over-week ROAS review.
  Retention: weekly email metrics review.
  TikTok: top video analysis.

TUESDAY — Brief & Build
  Copywriting: active copy requests (email, ads, product).
  Paid Ads: creative testing decisions.
  Creative Direction: shoot prep or asset review.
  TikTok: batch content day.

WEDNESDAY — Execute
  All departments: primary execution day.
  Shopify CRO: A/B test health checks.
  TikTok: second batch content day.
  Retention: campaign planning.

THURSDAY — Optimize & Segment
  Paid Ads: audience management.
  Retention: list health + at-risk segment review.
  Shopify CRO: test call (if sufficient data).
  TikTok: publish scheduled content.

FRIDAY — Report & Plan
  All departments: weekly report produced.
  Brand Strategy: receives all reports, issues brand pulse for next week.
  Retention: flow-library.md and segment-guide.md updated.
  Paid Ads: ad-playbook.md updated.
  All: next week planned.
```

## Approval Gates

Nothing ships without passing through these gates.

| Output | Approval Required From | SLA |
|---|---|---|
| Campaign narrative (drop) | Brand Strategy | 72h before briefing |
| Ad creative (all paid) | Creative Direction | Before any ad goes live |
| Product copy (PDP) | Copywriting + Brand Strategy | Before product page publishes |
| TikTok video | Creative Direction | 2h before scheduled post |
| Email (campaign) | Copywriting | Before scheduling in Klaviyo |
| A/B test hypothesis | Shopify CRO | Before test goes live |
| New Klaviyo flow | Retention | After QA checklist passes |
| Paid campaign launch | Paid Ads | Only after creative approved |

## Decision Authority

| Decision Type | Who Decides | Escalate If |
|---|---|---|
| Brand voice judgment call | Brand Strategy | Always final say |
| Kill an ad set | Paid Ads | No escalation needed |
| A/B test winner call | Shopify CRO | No escalation needed |
| Suppress email list segment | Retention | No escalation needed |
| Reject creative asset | Creative Direction | Pattern → escalate to Brand |
| Delay a drop | All departments must agree | Founder decision |
| Discount or promotion | Brand Strategy must approve | Never done unilaterally |

## P1 Emergency Protocol

When any department hits a P1 emergency, all non-P1 work stops until resolved.

```
P1 EXAMPLES:
  - Paid Ads ROAS < 1.0 (live spend, burning cash)
  - Email bounce rate > 0.5% (deliverability crisis)
  - Shopify checkout broken (zero revenue processing)
  - TikTok account restricted (top-of-funnel shut down)
  - Brand voice violation published (immediate retraction)

P1 RESPONSE:
  1. Department head identifies P1 — stops all other work
  2. Notifies all departments that P1 is active (via Slack #urgent)
  3. Isolates the problem — pauses any activity making it worse
  4. Resolves root cause before resuming anything else
  5. Post-mortem written in department's operations log
```

## The NCD Quality Filter

Before any output leaves any department, it must pass one check:

> **"Does this look, sound, and feel like NCD?"**

If the answer is no — or even "I'm not sure" — it goes back. The brand is the only non-negotiable. Revenue follows the brand. The brand does not follow revenue.
