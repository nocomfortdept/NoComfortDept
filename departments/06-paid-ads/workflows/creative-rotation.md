# Workflow: Creative Rotation
## Department: Paid Ads

Manage creative fatigue and maintain performance by rotating ad creative systematically.

---

## Creative Fatigue Signals

Watch for these indicators that a creative needs rotation:

| Signal | Threshold | Action |
|---|---|---|
| Frequency > 3.0 | On any ad set | Rotate creative |
| CTR drops > 30% week-over-week | — | Refresh hook or format |
| CPM increases > 40% with no targeting change | — | New creative needed |
| CPC doubles with no bid change | — | Kill creative, launch new |
| ROAS drops below 2.0 for 3 consecutive days | — | Kill ad set, review creative |

**Rule:** Review performance every 3 days. Kill underperformers at day 3. Don't wait.

---

## The Creative Testing Ladder

```
STEP 1 — Hook Test
  Same body content, 4 different opening hooks (0–2 seconds)
  Hypothesis: different hooks attract different buyers

STEP 2 — Format Test
  Best hook from Step 1, in 3 formats (static / video / carousel)
  Hypothesis: format changes CVR for same audience

STEP 3 — Audience Test
  Best format from Step 2, across 3 audiences (broad / interest / LLA)
  Hypothesis: same creative, different audiences = different ROAS

STEP 4 — Copy Test
  Best creative/audience from Step 3, with 3 copy angles
  Hypothesis: different primary text = different click intent

STEP 5 — Scale
  Winner combination → CBO at 20% higher budget
```

---

## Creative Naming Convention

`NCD-[Audience]-[Format]-[CopyAngle]-[Version]`

Examples:
- `NCD-Cold-Video-Identity-v1`
- `NCD-Warm-Static-Urgency-v2`
- `NCD-Hot-Carousel-QualitySpec-v1`

Always name before launching. No unnamed ads.

## Rotation Schedule

| Week | Action |
|---|---|
| Week 1 | Launch hook test (4 variants) |
| Week 2 | Kill bottom 2, add format test |
| Week 3 | Kill bottom format, add audience test |
| Week 4 | Kill bottom audience, add copy test |
| Week 5+ | Scale winner, begin new hook test in parallel |

**Never run fewer than 3 active ad creatives per ad set.** One creative is never enough to optimize against.
