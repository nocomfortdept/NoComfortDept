# TikTok Growth — Daily & Weekly Schedule
## Department: 04 | Employee: TikTok Creative Director

---

## Main Objective

Build TikTok as NCD's primary organic growth and top-of-funnel acquisition engine. Convert scroll-stoppers into brand-aware traffic that lands on the Shopify store already convinced. Grow the account from unknown to category authority in masculine streetwear.

**North star metric:** TikTok-attributed Shopify revenue (tracked via UTM). Secondary: link-in-bio click-through rate.

---

## Daily Responsibilities

### Every Day (45–60 min)

| Time | Task | Output |
|---|---|---|
| Morning | Check TikTok analytics from yesterday — views, watch time, profile visits, link clicks | Daily performance log entry |
| Morning | Check what's trending in FYP (masculine content, fashion, self-improvement, streetwear) | Trend note if relevant |
| Morning | Verify link-in-bio UTM is correct and landing page is live | System check |
| Core work | Execute today's video from content calendar | Video posted |
| Post-posting | Monitor first 30 minutes of engagement — comments, shares, saves | Response to comments |
| EOD | Update content calendar with today's actual post and preliminary results | Calendar current |

### Drop-Week Daily Additions
- Post 2x per day minimum during drop window
- Monitor link clicks in real-time for first 2 hours post-drop
- Screenshot/save any organic customer comments for use in social proof content

---

## Weekly Responsibilities

### Monday — Content Planning
- [ ] Review last week's performance: which pillar performed best?
- [ ] Load this week's brand campaign narrative from Brand Strategy
- [ ] Finalize content calendar for the week (`workflows/content-calendar.md`)
- [ ] Write hooks and captions for this week's batch (`workflows/hook-writing.md`)
- [ ] Confirm creative assets are available from Creative Direction

### Tuesday — Production Day
- [ ] Film or direct filming of this week's content (where applicable)
- [ ] Edit or brief editor on edits for each video
- [ ] Batch caption writing — all 5–7 videos for the week
- [ ] Brief any UGC creators for the week if applicable

### Wednesday — Scheduling & Publishing
- [ ] Schedule week's videos (use TikTok scheduler for off-peak times)
- [ ] Confirm all UTMs are appended to link-in-bio
- [ ] If drop this week — confirm LP is live with CRO before scheduling drop content

### Thursday — Collaboration & Briefs
- [ ] Submit LP brief to Shopify CRO if new landing page needed next week
- [ ] Submit TikTok ad creative brief to Paid Ads for any paid amplification
- [ ] Review week's performance trend — adjust remaining content if needed

### Friday — Analytics & Reporting
- [ ] Pull weekly analytics: views, followers gained, profile visits, link clicks, LP CVR
- [ ] Identify top-performing hook angle of the week
- [ ] Update hook-vault with any new high-performers
- [ ] Log in weekly performance table
- [ ] Brief next week's content angle to Creative Direction (asset needs)

## Example Daily Workflow (Standard Day — No Drop)

```
08:00  Check TikTok analytics
       Yesterday's video: 48K views (above average), 312 profile visits, 89 link clicks
       Hook type: "POV" text hook — strong performer
       → Log in hook-vault: POV hooks performing +35% above average this week
       → Note: add 2 more POV hooks to this week's remaining content

08:20  FYP scan (15 min)
       Trending in masculine content: 5am cold water plunge videos
       Does this fit NCD? Yes — Identity Mirror pillar
       → Add to Tuesday brief: "Dark morning training content — NCD worn naturally"

08:35  Check link-in-bio → UTM correct, LP live. System healthy.

08:40  Post today's scheduled video (fabric macro — Product Truth)
       → Manually add caption (was pre-written Monday)
       → Post between 8–10am for optimal reach

08:55  Monitor first 30 minutes
       → 2,100 views in 30 min (normal for this account)
       → 3 comments: answer 2 (product questions), ignore 1 (troll)

09:15  Update content calendar with today's post stats

09:30  Write tomorrow's TikTok caption from content calendar brief

09:45  Done
```

## Example Weekly Workflow (Drop Launch Week)

```
MON  Analytics: last week avg 32K views/video. Hook performance: identity hooks > product truth.
     Load Drop 5 narrative: "The Standard."
     Content plan:
     - Mon: Drop teaser — "Something is coming."
     - Tue: Fabric detail — Product Truth
     - Wed: "Drop 5 drops tomorrow." — Drop Mechanics
     - Thu (Drop Day AM): "Drop 5 is live." — Drop Mechanics
     - Thu (Drop Day PM): Stock update
     - Fri: "X units left." or sold-out announcement
     Write all hooks and captions.

TUE  Film fabric macro video + identity mirror clip (dark morning training).
     Edit both. Check: crushed blacks, intentional posture, brand music.
     Brief Creative Direction: need B-roll product footage by Wednesday EOD.

WED  Post teaser video with "Drop 5 — Tomorrow." caption.
     Monitor: 67K views in 4 hours. 891 profile visits. 234 link clicks.
     LP is live (confirmed with CRO). Link-in-bio updated.

THU  Drop Day AM: "Drop 5 is live." video posted at 8:00am.
     Monitoring every 30 min. By noon: 102K views, 1,847 link clicks.
     Drop Day PM: Post stock update "31 units left."

FRI  Sold out at 11pm Thursday. Post: "Gone. Archive."
     Pull analytics: total drop week link clicks: 4,211. LP CVR: 4.8%.
     Log in performance table. Add "Drop Mechanics" to strong performers this week.
     Brief next week: post-drop authority content. Keep momentum.
```
